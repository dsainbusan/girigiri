# ギリギリ(기리기리) — 동네 가게 마감 임박 음식 긴급 구제 서비스

14기 A반 2조 (조이름: 다이스키)
조장: 송보미 | 팀원: 강노은, 김태훈, 문창호, 송채현

## 1. 프로젝트 주제

기리기리(ギリギリ)는 빵집, 편의점, 반찬가게, 도시락집 등에서 영업 마감 시간까지 판매되지 않아 폐기 위기에 놓인 음식을, 마감 직전 실시간 헐값 판매·예약으로 연결하는 동네 기반 음식물 낭비 방지 플랫폼입니다.

소상공인에게는 폐기 손실을 줄일 판매 기회를, 소비자에게는 저렴한 가격으로 신선한 식품을 구매할 기회를 제공합니다.

## 2. 프로젝트 기획 배경 및 목표

### 2.1 기획 배경

**① 사장님 측 문제점**
- 마감 임박 상품이 판매되지 않으면 전량 폐기되어 손실이 발생한다.
- 재고와 할인 판매 정보를 소비자에게 실시간으로 알릴 방법이 부족하다.
- 매장별로 할인 정보를 직접 홍보해야 하는 번거로움이 있다.

**② 소비자 측 문제점**
- 주변 매장의 마감 세일 정보를 일일이 확인해야 한다.
- 할인 상품이 언제, 어디에서 나오는지 알기 어렵다.
- 저렴하게 살 수 있는 상품을 발견할 기회가 부족하다.

### 2.2 프로젝트 목표
- 소상공인의 음식 폐기 및 재고 손실 감소
- 소비자에게 합리적인 가격의 신선한 식품 제공
- 음식물 쓰레기 문제와 소상공인 매출 문제를 동시에 해결
- 지역 내 매장과 소비자를 연결하여 지속 가능한 지역 소비 환경 구축

### 2.3 주요 타겟층
- 영업 마감 시간이 명확한 동네 소상공인(빵집, 편의점, 반찬가게, 도시락집 등 마감 전 재고가 발생하는 매장)
- 가성비와 신선도를 중시하는 1인 가구 및 대학생

## 3. 주요 기능

### 3.1 회원 및 인증
- 소셜 로그인(카카오/구글/라인 OAuth2)과 자체 이메일 회원가입
- 이메일 OTP 인증, 휴대폰 인증, 이메일 찾기, 비밀번호 재설정
- 회원 정보 수정, 탈퇴, 소셜 계정 연동/해제
- **권한(role)은 일반 사용자(USER) / 점주(OWNER) / 운영자(ADMIN) 세 가지**이다. 로그인하면 role에 따라 화면이 나뉜다.
- 점주(OWNER)는 헤더 토글로 **점주 모드 / 유저 모드**를 전환한다. 실제 role은 바뀌지 않고 현재 보기 모드(viewMode)만 세션에 저장하며, **권한 검사는 항상 viewMode가 아닌 실제 role 기준**이다.
- 사장님은 입점 신청 후 운영자(슈퍼어드민)의 승인을 받아야 매장을 운영할 수 있다. 운영자(ADMIN)는 유저·점주 화면에 직접 접근할 수 없고 전용 화면만 사용한다.

### 3.2 사장님용 매장 운영 및 재고 등록
- 매장 정보(영업시간·위치·카테고리)와 상품 정보를 등록·수정하고, 마감 전 남은 상품을 사진과 함께 간단 등록(품목, 원가, 수량)
- 자주 올리는 상품을 템플릿으로 저장
- 각 매장의 POS에서 JSON 데이터를 받아온다고 가정하여 메뉴·재고 자동 동기화(연결/재동기화/해제)
- 재고와 마감 시간을 기준으로 할인율 자동 계산
- 오늘 등록/판매 현황 대시보드, 판매·폐기 통계 그래프, 음식 구제 목표 설정과 달성 현황
- 매장 공지 및 소식 등록·관리, 운영자 공지 확인
- 고객 리뷰에 답글 작성·삭제

### 3.3 소비자용 실시간 탐색
- 카카오맵 기반으로 내 주변 마감세일 가게를 지도와 카드로 확인
- 카테고리(베이커리/반찬/도시락/카페 등) 필터, 키워드 검색, 할인율·거리·마감 임박순 정렬
- 상품 상세, 가게 상세(정보·영업시간·상품·리뷰)
- 관심 가게 찜하기와 찜 목록
- **SSE(Server-Sent Events)** 로 마감세일 시작과 예약 상태를 실시간 알림으로 전달하고, 인앱 알림함과 알림 설정(찜 알림 켜기/끄기)을 제공
- AI를 활용한 리뷰 요약

### 3.4 예약 · 결제 · 픽업
- 원하는 상품을 선결제한 뒤 픽업 시간대 예약, 픽업 코드(QR/번호) 발급으로 현장 확인
- 예약 상태: 결제 대기 → 예약 확정 → 상품 준비 → 픽업 완료 (그 외 취소, 노쇼, 환불 완료). 결제 대기 시간이 지나면 자동 취소된다.
- PortOne 테스트 결제 연동. 프론트에서 결제한 뒤 **반드시 백엔드에서 금액을 재검증**한다.
- 손님 취소·매장 취소와 환불 처리
- 노쇼 방지: 자정이 지나도 픽업하지 않은 예약은 자동으로 노쇼 처리하고, 매장의 취소율을 기준으로 신뢰도를 평가해 일정 기준을 넘으면 자동 정지한다.
- **결제 영수증 PDF**: 백엔드 결제 검증이 끝나면 거래내역(가게·상품·결제금액·결제수단·일시)과 픽업 QR을 담은 PDF를 발급한다. 영수증이 곧 픽업권이며 마이페이지에서 다시 내려받을 수 있다.
- **쿠폰**: 가입 시 자동 지급되는 웰컴 쿠폰, 매장 사정으로 취소됐을 때 지급되는 보상 쿠폰, 코드를 입력해 받는 프로모션 쿠폰, 운영자가 발행하는 매장 지정·지역 지정 쿠폰. 체크아웃에서 선택해 사용하며 대상 매장·지역과 최소 주문 금액을 검증한다.
- **주문 신고**: 픽업 완료 후 48시간 이내에 주문 상세에서 신고할 수 있다(같은 주문에 처리 중인 신고가 있으면 불가).

### 3.5 신뢰 및 기록
- 이용 후 가게 리뷰와 별점(픽업 완료한 예약 1건당 리뷰 1개), 내 리뷰 관리
- **절약 가계부**: 이번 달·누적 절약액과 절약률, 월별 그래프, 카테고리별 소비·절약 분석, 절약 목표와 달성률, CSV/PDF 내보내기
- 구제한 음식 개수와 CO₂ 절감 환산 수치 기록(환경 기여도 시각화)
- 활동 실적에 따른 뱃지 18종과 사용자 랭킹
- 문의 게시판(등록·상세·댓글)

### 3.6 문서 자동 생성 (차별 포인트)
결제·정산·환경 데이터를 유저와 매장이 문서로 자동 산출·저장한다.

| 문서 | 대상 | 형식 |
|---|---|---|
| 결제 영수증(픽업 QR 포함) | 유저 | PDF |
| 판매·폐기 리포트(품목별 등록/판매/폐기 수량, 매출·할인액, 구제율, CO₂ 절감 환산, 일간 기본·주간 확장) | 매장 | Excel + PDF |
| 정산 내역(상세 포함) | 매장 | Excel + PDF |
| 절약 가계부 | 유저 | CSV + PDF |
| 일간 플랫폼 리포트, 정산 이체 내역, 회원·매장 목록 | 운영자 | Excel + PDF |

### 3.7 슈퍼어드민(플랫폼 운영)
- 통계 대시보드: 회원수·거래량·거래액·구제량, 어제 대비 증감, 처리 대기 현황, **지역별 현황(마감 상품 소진율)** 과 지역 → 매장 드릴다운
- 회원 관리(조회·정지·탈퇴·일괄 처리), 매장 관리(입점 승인/반려·정지·재고·주문 조회), 주문 조회
- 정산 관리(지급 처리), 공지사항 관리, 카테고리·공통코드 관리
- **신고·문의 관리**: 신고 상세에서 신고 대상 주문을 확인하고, 픽업 완료 주문은 **관리자 환불**(PG 환불 → 주문 환불 완료 → 신고 처리완료와 답변 저장)로 처리한다. PG 환불이 실패하면 주문·신고 상태는 그대로 두고 다시 시도할 수 있다.
- **쿠폰 관리**: 웰컴/보상 쿠폰 할인율 설정, 코드형 캠페인, 지역별 현황에서 소진율이 낮은 매장에 매장 지정 쿠폰 발행, **선택한 시도의 회원에게 지역 지정 쿠폰을 바로 발행**(대상 회원 수·예상 비용 미리보기, 알림 선택)

### 3.8 고객 지원 챗봇
- Gemini API 기반 챗봇. 회원용(마이페이지, 본인 예약 조회 가능)과 비회원용(마케팅 홈·FAQ, 예약 조회 불가, 요청 횟수 제한)으로 나누고 API 키도 분리했다.

### 3.9 향후 확장
- 환경 기여도 인증서 PDF(누적 CO₂ 절감량, SNS 공유용)
- 픽업 시간대 슬롯 관리

## 4. 주요 화면 UI

유저·점주 화면은 모바일 크기(고정폭 약 420px, 화면 중앙 정렬)를 기준으로 설계하고, 슈퍼어드민 화면은 데스크톱 레이아웃을 별도로 사용한다. 화면 언어는 한국어/일본어/영어를 지원한다.

- **로그인 / 모드 선택**: 소셜·이메일 로그인, 점주는 점주 모드 / 유저 모드 전환, 입점 신청
- **홈 화면**: 지도 기반으로 내 주변 마감세일 가게를 카드로 나열, 할인율과 남은 시간 강조
- **상품 상세**: 원가/할인가 비교, 남은 수량, 픽업 가능 시간, 예약 버튼
- **사장님 대시보드**: 오늘 등록 상품 현황, 판매/폐기 통계 그래프, 리포트 다운로드(Excel/PDF), POS 연동, 정산
- **마이페이지**: 예약 내역, 픽업 QR, 결제 영수증 PDF 다시 받기, 누적 절약 금액과 환경 기여도(예: "이산화탄소 O kg 절감"), 절약 가계부, 쿠폰함
- **알림함**: 찜한 가게의 마감세일 시작 알림과 예약·결제 상태 알림
- **슈퍼어드민**: 통계 대시보드, 회원·매장·주문·정산 관리, 신고·환불, 쿠폰·공지 운영
- **비회원 화면**: 마케팅 홈, FAQ, 이용약관·정책, 비회원 챗봇

## 5. 개발 환경 및 사용 기술

### 5.1 개발 환경
- Frontend: Thymeleaf + JavaScript
- Backend: Java 21, Spring Boot 3.5
- DB: MySQL
- 파일·매출 데이터 저장: Supabase

### 5.2 사용 라이브러리 / Open API
| 구분 | 기술 |
|---|---|
| 인증 | Spring Security + OAuth2 Client (카카오/구글/라인), 이메일 OTP(메일 발송) |
| 지도/위치 | 카카오맵 API |
| 실시간 알림 | SSE (Server-Sent Events) |
| 결제 | 아임포트(PortOne) 테스트 결제 — 결제 금액 백엔드 재검증, 환불 |
| QR 코드 | ZXing — 픽업 확인 및 영수증 삽입 |
| PDF | Thymeleaf HTML → openhtmltopdf — 영수증·리포트·가계부 |
| Excel | Apache POI — 판매·폐기 리포트, 정산 |
| AI | Gemini API — 고객 지원 챗봇, AI 리뷰 요약 |

### 5.3 인증 및 화면 구조
- role 기반 라우팅(USER/OWNER/ADMIN) + 점주의 viewMode 세션 전환으로 점주 모드/유저 모드 겸용
- 운영자(슈퍼어드민)는 별도 권한과 접근 제어로 분리해 입점 승인과 운영 기능만 사용
- 유저·점주는 모바일 고정폭 컨테이너 기반 단일 레이아웃, 슈퍼어드민은 데스크톱 전용 레이아웃

## 7. 참고 사이트 및 차별점

- **투굿투고(Too Good To Go)**: 유럽에서 실제 운영 중인 폐기 임박 음식 판매 서비스. 마감 임박 재고를 실시간으로 헐값에 연결한다는 핵심 구조를 참고했다.
- **라스트오더(국내 유사 서비스)**: 국내에 유사 서비스가 있어 아래 차별점을 분명히 한다.

본 서비스의 차별점
1. 동네 밀착형 모바일 UI
2. 환경 기여도 시각화(누적 절약·CO₂ 절감)
3. 픽업 QR 시스템과 노쇼·취소율 기반 매장 신뢰도 관리
4. 결제 영수증·정산·판매/폐기 리포트 등 문서(PDF/Excel) 자동 생성
5. SSE 기반 실시간 알림으로 마감세일과 예약 상태 안내
6. 절약 가계부·뱃지·랭킹으로 지속적인 이용 동기 제공
7. 신고 → 운영자 확인 → 환불로 이어지는 분쟁 처리와 지역 단위 쿠폰·통계 운영 기능
