## 1. 프로젝트 주제

빵집, 편의점, 반찬가게, 도시락집 등에서 영업 마감 시간까지 팔리지 않아 폐기될 위기에 놓인 음식을, 마감 시간 전 실시간으로 헐값에 판매·예약할 수 있게 연결해주는 동네 기반 음식물 낭비 방지 서비스.

## 2. 기획 배경 및 목표

- **사장님 입장**: 마감이 다가올수록 팔리지 않은 음식은 전량 폐기 손실이 된다. 그러나 얼마나 남았는지, 언제까지 할인해 팔지 손님에게 실시간으로 알릴 방법이 마땅치 않다.
- **소비자 입장**: 저렴하게 사고 싶어도 어느 가게가 언제 마감세일을 하는지 알기 어렵고, 가게별 마감 시간을 일일이 확인하기도 번거롭다.
- **목표**: 소상공인의 폐기 손실을 줄이고, 소비자에게는 합리적인 가격에 신선식품/베이커리를 살 기회를 제공해 음식물 쓰레기 문제와 소상공인 매출 문제를 동시에 해결한다.
- **주요 타겟층**: 마감 시간이 명확한 동네 소상공인, 가성비를 중시하는 1인 가구·대학생.

### 3.4 예약 · 결제 · 픽업
- 선결제 후 픽업 시간대 예약. 결제는 PortOne 테스트 결제이며 **프론트 결제 후 백엔드에서 금액을 반드시 재검증**한다.
- 재고 선차감 후 결제 대기(pending) → 결제 확정(confirmed) → 매장 수락(ready) → 픽업완료(picked). 결제 대기 시간 초과 시 자동 취소.
- 픽업 코드(QR/번호) 발급, 매장 측 QR/코드 스캔 픽업 확인(일괄 처리 포함)
- 손님 취소·매장 취소(환불 연동), 자정이 지나도록 픽업하지 않으면 자동 노쇼 처리 + 매장 신뢰도(취소율) 관리·자동 정지 **[변경: "가게 노쇼 방지"를 신뢰도 제도로 구체화]**
- 결제 영수증 PDF(QR 포함): 결제 검증 후 발급, 마이페이지에서 재다운로드
- 쿠폰: 쿠폰 정책, 가입 환영 쿠폰, 매장 캠페인 쿠폰 받기 **[추가]**
- **[미완]** 픽업 시간대 슬롯 관리(선택 항목, 미착수)

## 5. 개발 환경 및 사용 기술

### 5.1 개발 환경
- Frontend: Thymeleaf + JavaScript (모바일 고정폭 웹, BEM + 디자인 토큰 CSS)
- Backend: Java 21, Spring Boot 3.5
- DB: MySQL (JPA/Hibernate)
- 이미지·영수증 저장: Supabase Storage

### 5.2 라이브러리 / Open API
| 구분 | 기술 |
|---|---|
| 인증 | Spring Security + OAuth2 Client (카카오/구글/라인), 이메일 OTP(spring-boot-starter-mail) |
| 지도/위치 | 카카오맵 API, 카카오 지오코딩 |
| 실시간 알림 | **SSE (SseEmitter)** [변경: 기존 WebSocket/STOMP] |
| 결제 | PortOne(아임포트) 테스트 결제 + 서버 검증·환불 |
| QR | ZXing |
| PDF | Thymeleaf HTML → openhtmltopdf |
| Excel | Apache POI |
| AI | Gemini API (챗봇, 리뷰 요약, 상품 사진 태깅) |

### 5.3 인증 및 화면 구조
- role 기반 라우팅 + `viewMode` 세션 전환으로 관리자의 관리자/사용자 모드 겸용
- 권한 검사는 실제 role, 화면 분기만 viewMode
- 슈퍼어드민 영역은 별도 인터셉터(`SuperAdminAccessInterceptor`)로 접근 제어

## 7. 참고 사이트 및 차별점

- **투굿투고(Too Good To Go)**: 폐기 임박 음식 판매 서비스 — 마감 임박 재고를 실시간으로 헐값에 연결하는 핵심 구조를 참고
- **라스트오더(국내)**: 유사 서비스 — 아래 차별점으로 구분

본 서비스의 차별점
1. 동네 밀착형 모바일 UI(고정폭 420px)
2. 환경 기여도·절약 가계부(누적 절약, CO₂ 절감, 뱃지·랭킹)
3. 픽업 QR 시스템 + 노쇼/취소율 기반 매장 신뢰도 관리
4. 문서 자동 생성(영수증·정산·판매/폐기 리포트·가계부)
5. 운영 투명성: 신고 → 운영자 확인 → 환불까지 이어지는 분쟁 처리 흐름, 쿠폰·정산·통계 대시보드
6. 한/일/영 다국어 지원과 AI 고객 지원 챗봇
