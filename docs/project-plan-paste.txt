ギリギリ(기리기리) — 동네 가게 마감 임박 음식 긴급 구제 서비스
14기 A반 2조 (조이름: 다이스키)
조장: 송보미   팀원: 강노은, 김태훈, 문창호, 송채현

1. 프로젝트 주제
기리기리(ギリギリ)는 빵집, 편의점, 반찬가게, 도시락집 등에서 영업 마감 시간까지 판매되지 않아 폐기 위기에 놓인 음식을 마감 직전 실시간 헐값 판매 및 예약으로 연결하는 동네 기반 음식물 낭비 방지 플랫폼입니다.
소상공인에게는 폐기 손실을 줄일 수 있는 판매 기회를 제공하고, 소비자에게는 저렴한 가격으로 신선한 식품을 구매할 수 있는 기회를 제공합니다.

2. 프로젝트 기획 배경 및 목표
2.1 기획 배경
① 사장님 측 문제점
- 마감 임박 상품이 판매되지 않을 경우 전량 폐기되어 손실 발생
- 재고 및 할인 판매 정보를 실시간으로 소비자에게 알릴 수 있는 방법 부족
- 매장별로 직접 할인 정보를 홍보해야 하는 번거로움
② 소비자 측 문제점
- 주변 매장의 마감 세일 정보를 일일이 확인해야 하는 불편함
- 할인 판매 상품이 언제, 어디에서 발생하는지 알기 어려움
- 저렴하게 구매할 수 있는 상품을 발견할 기회 부족
2.2 프로젝트 목표
- 소상공인의 음식 폐기 및 재고 손실 감소
- 소비자에게 합리적인 가격의 신선한 식품 제공
- 음식물 쓰레기 문제와 소상공인의 매출 문제를 동시에 해결
- 지역 내 매장과 소비자를 연결하여 지속 가능한 지역 소비 환경 구축
2.3 주요 타겟층
- 영업 마감 시간이 명확한 동네 소상공인
- 빵집, 편의점, 반찬가게, 도시락집 등 마감 전 재고가 발생하는 매장
- 가성비와 신선도를 중시하는 1인 가구 및 대학생

3. 주요 기능
3.1 회원 및 인증
- 소셜 로그인(카카오/구글/라인 OAuth2) 및 자체 이메일 회원가입 지원
- 이메일 OTP/휴대폰 인증, 이메일 찾기 및 비밀번호 재설정 지원
- 로그인 시 role을 확인하여 화면 분기 — role은 일반 사용자(USER) / 점주(OWNER) / 운영자(ADMIN) 세 가지이며, 일반 사용자는 유저 홈으로, 점주는 점주 대시보드로, 운영자는 슈퍼어드민 화면으로 진입
- 점주는 두 모드를 모두 사용 가능. 실제 role은 고정하고 '현재 보기 모드(viewMode)'만 세션에 저장하여 헤더 토글로 '점주 모드 / 유저 모드'를 전환. 권한 체크는 viewMode가 아닌 실제 role 기준
- 사장님은 입점 신청 후 슈퍼어드민(운영자)의 승인/반려를 거쳐 매장을 운영하며, 운영자는 유저·점주 화면에 직접 접근할 수 없고 전용 화면만 사용
- 슈퍼어드민 운영 기능 제공 — 통계 대시보드(회원수·거래량·구제량, 지역별 마감 상품 소진율 현황과 지역별 매장 드릴다운), 회원·매장·주문 관리, 정산 지급 관리, 공지사항·공통코드 관리
- 회원 정보 수정, 탈퇴, 소셜 계정 연동/해제 지원
3.2 사장님용 매장 운영 및 재고 등록 기능
- 매장 정보(영업시간·위치·카테고리) 및 상품 정보를 등록·수정하고, 마감 전 남은 상품을 사진과 함께 간단 등록(품목, 원가, 수량)
- 자주 올리는 상품을 템플릿으로 저장
- 오늘 등록/판매 현황을 한눈에 확인
- 각 매장의 포스기에서 JSON 데이터를 받아온다고 가정하여 메뉴 및 재고 자동 동기화
- 재고와 마감 시간을 기준으로 할인율을 자동 계산
- 매장 대시보드에서 판매·폐기 현황 및 통계 확인
- 음식물 구제 목표를 설정하고 달성 현황 확인
- 매장 공지 및 소식 등록·관리
- 고객 리뷰에 답글 작성
3.3 소비자용 실시간 탐색 기능
- 내 주변 마감세일 중인 가게를 카카오맵 기반 지도로 확인
- 카테고리(베이커리/반찬/도시락/카페 등) 필터링
- 키워드 검색 및 할인율·거리·마감 임박순 정렬
- 상품 및 가게 상세정보 확인
- 관심 가게 찜하기 및 마감세일 시작 시 SSE(Server-Sent Events) 기반 실시간 알림
- 인앱 알림함을 통해 받은 알림을 확인하고, 알림 설정(찜 알림 켜기/끄기) 제공
- AI를 활용한 리뷰 요약 기능 제공
3.4 예약 · 결제 · 픽업 기능
- 원하는 상품 선결제 후 픽업 시간대 예약
- 픽업 코드(QR/번호) 발급으로 현장 확인
- 결제 상태를 결제 대기 → 예약 확정 → 상품 준비 → 픽업 완료 단계로 관리 (그 외 취소·노쇼·환불 완료 상태 포함)
- 결제 대기 시간 경과 시 자동 취소 처리
- PortOne 테스트 결제 연동 및 결제 금액 백엔드 재검증
- 손님 취소·매장 취소 및 환불 처리
- 노쇼 방지 — 자정이 지나도 픽업하지 않은 예약은 자동 노쇼 처리하고, 매장 취소율을 기준으로 신뢰도를 평가해 기준 초과 시 자동 정지하는 가게 신뢰도 평가 제도 운영
- 결제 영수증 PDF 자동 생성 — 백엔드 결제 검증 완료 후 거래내역(가게·상품·결제금액·결제수단·일시)과 픽업 QR을 담은 영수증 PDF를 발급·다운로드. 영수증이 곧 픽업권 역할
- 마이페이지에서 결제 영수증 PDF를 다시 다운로드
- 쿠폰 정책 및 쿠폰 배포 기능 — 가입 시 웰컴 쿠폰, 매장 사정 취소 시 보상 쿠폰, 코드 입력형 프로모션 쿠폰, 운영자가 발행하는 매장 지정·지역 지정 쿠폰(선택한 시도의 회원에게 바로 발급)
- 주문 신고 및 환불 — 픽업 완료 후 48시간 이내 주문 신고, 운영자가 확인 후 환불 처리하고 신고에 답변
3.5 신뢰 및 기록 기능
- 이용 후 가게 리뷰 및 별점 (픽업 완료한 예약 1건당 리뷰 1개)
- 가게별 리뷰 관리 및 사용자 리뷰 확인
- 누적 절약 금액, 구제한 음식 개수 등 개인 기록 대시보드(환경 기여도 시각화)
- 월별 절약액, 그래프, 카테고리 분석 및 절약 목표를 제공하는 절약 가계부
- 구제한 음식 개수와 CO₂ 절감 환산 수치를 기록
- 활동 실적에 따른 뱃지(18종) 및 사용자 랭킹 제공
- 문의 게시판을 통한 사용자 문의 접수 및 관리
- Gemini 기반 고객 지원 챗봇 — 회원용(본인 예약 조회 가능)과 비회원용(예약 조회 불가, 요청 횟수 제한)으로 구분
3.6 문서 자동 생성 기능 — 차별 포인트
결제·정산·환경 데이터를 유저와 매장이 문서로 자동 산출·저장할 수 있게 한다.
- 결제 영수증 PDF(유저) — 마이페이지에서 다시 내려받기 가능
- 매장 판매·폐기 리포트(매장, Excel + PDF) — 품목별 등록/판매/폐기 수량, 매출·할인액, 구제율(판매÷등록), CO₂ 절감 환산을 포함하며 일간 리포트를 기본으로 제공. 데이터 누적 시 주간 확장
- 매장 정산 내역(Excel + PDF), 절약 가계부(유저, CSV + PDF), 일간 플랫폼 리포트(운영자, Excel + PDF)
- (옵션, 향후 확장) 환경 기여도 인증서 PDF — 누적 CO₂ 절감량을 인증서 형태로 제공하고 SNS 공유에 활용

4. 주요 화면 UI
※ 유저·점주 화면은 모바일 크기(고정폭 약 420px, 화면 중앙 정렬)를 기준으로 설계하고, 슈퍼어드민 화면은 데스크톱 레이아웃을 별도로 사용한다.
- 로그인 / 모드 선택 화면: 소셜·이메일 로그인 버튼, 점주는 '점주 모드 / 유저 모드' 선택, 입점 신청
- 홈 화면: 지도 기반으로 내 주변 마감세일 가게를 카드 형태로 나열, 할인율과 남은 시간 강조 표시
- 상품 상세 화면: 원가/할인가 비교, 남은 수량, 픽업 가능 시간, 예약 버튼
- 사장님 대시보드: 오늘 등록한 상품 현황, 판매/폐기 절감 통계 그래프, 리포트 다운로드(Excel/PDF) 버튼
- 마이페이지: 예약 내역, 픽업 QR코드, 결제 영수증 PDF 다시 받기, 누적 절약 금액 및 환경 기여도(예: '이산화탄소 O kg 절감'), 절약 가계부, 쿠폰함
- 알림함: 찜한 가게의 마감세일 시작 알림 및 예약·결제 상태 알림 확인
- 슈퍼어드민 화면: 통계 대시보드, 입점 신청 승인/반려, 회원·매장·주문·정산 관리, 신고·환불, 쿠폰(지역 지정 발행 포함) 및 공지 운영

5. 개발 환경 및 사용 기술
5.1 개발 환경
- Frontend: Thymeleaf + JavaScript (유저·점주는 모바일 고정폭 웹, 슈퍼어드민은 데스크톱 화면)
- Backend: Java 21, Spring Boot 3.5
- DB: MySQL
- 파일·매출 데이터 저장: Supabase
5.2 사용 라이브러리 / Open API
- 인증: Spring Security + OAuth2 Client — 카카오/구글/라인 소셜 로그인, 이메일 OTP 메일 발송
- 지도/위치: 카카오맵 API — 주변 가게 지도 표시
- 실시간 알림: SSE — 찜한 가게 마감세일 시작 및 예약 상태 등의 실시간 알림
- 결제: 아임포트(PortOne) 테스트 결제 연동 — 소액 예약금 처리(프론트 결제 후 반드시 백엔드에서 금액 재검증), 환불
- QR코드 생성: ZXing — 픽업 확인 및 영수증 삽입용
- PDF 생성: Thymeleaf HTML → openhtmltopdf — 결제 영수증·매장 리포트·가계부
- Excel 생성: Apache POI — 매장 판매·폐기 리포트, 정산
- AI: Gemini — 챗봇 및 AI 리뷰 요약
5.3 인증 및 화면 구조
- role 기반 라우팅(USER/OWNER/ADMIN) + viewMode 세션 전환으로 점주의 점주 모드/유저 모드 겸용 지원
- 슈퍼어드민(운영자) 권한을 별도로 두어 입점 승인 및 운영 관리 기능을 분리
- 유저·점주는 모바일 고정폭 컨테이너 기반 단일 레이아웃, 슈퍼어드민은 데스크톱 전용 레이아웃

7. 참고 사이트 및 차별점
- 투굿투고(Too Good To Go) — 유럽에서 실제 운영 중인 폐기 임박 음식 판매 서비스. 마감 임박 재고를 실시간으로 헐값에 연결한다는 핵심 구조를 참고
- 라스트오더(국내 유사 서비스) — 국내에 유사 서비스가 존재하므로 '기존 서비스와의 차별점'을 명확히 제시
본 서비스의 차별점:
- 동네 밀착형 모바일 UI
